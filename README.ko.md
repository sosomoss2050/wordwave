# WordWave — 가사 모션 비디오 메이커

> [852wa/JIZURA](https://github.com/852wa/JIZURA) (MIT License, Copyright (c) 2026 hakoniwa)의 포크입니다. 원작자 852wa님의 훌륭한 작품과 오픈소스에 감사드립니다.

**온라인 사용:** [English](https://sosomoss2050.github.io/wordwave/) · [简体中文](https://sosomoss2050.github.io/wordwave/zh-hans/index.html) · [한국어 (앱 버전)](https://sosomoss2050.github.io/wordwave/ko/index.html)

WordWave는 가사를 브라우저에서 문자 애니메이션 MV로 바꿔줍니다 — MP4(H.264 + AAC) 출력, 자동 비트 싱크, 원본 JIZURA 엔진의 860+ 표현 부품과 27가지 스타일.

전체 가이드(기능, headless 자동화, fine-tune 워크플로): **[README.en.md](README.en.md)** 참조.
