# WordWave — Pembuat Video Lirik

> Fork dari [852wa/JIZURA](https://github.com/852wa/JIZURA) (MIT License, Copyright (c) 2026 hakoniwa). Terima kasih banyak kepada penulis asli 852wa atas karya dan open source-nya.

**Gunakan online:** [English](https://sosomoss2050.github.io/wordwave/) · [简体中文](https://sosomoss2050.github.io/wordwave/zh-hans/index.html) · [Bahasa Indonesia (versi app)](https://sosomoss2050.github.io/wordwave/id/index.html)

WordWave mengubah lirik menjadi video animasi teks (MV) langsung di browser — MP4 (H.264 + AAC), sinkronisasi beat otomatis, 860+ bagian ekspresi dan 27 gaya dari mesin asli JIZURA.

Panduan lengkap (fitur, headless automation, alur kerja fine-tune): lihat **[README.en.md](README.en.md)**.

- Proyek asli: https://github.com/852wa/JIZURA
- Penulis asli: https://github.com/852wa
- Lisensi: MIT — output video/gambar milik pembuatnya.
