## Agent 使用规则

1. 用户**没提风格** → 判断歌曲情绪 → 按上表选首选，**直接出片**（附一句"我按歌曲情绪选了 X 风格，不满意可以换"）
2. 用户**提了模糊描述**（"酷一点""温柔一点"）→ 对应到表内风格再出片
3. 用户**明确要挑** → 展示本目录（只展示 id+中文一句话，不倾倒全部细节）
4. 拿不准 → omakase 全自动 + 记下 seed
5. 每次出片**必须回传 seed**，方便复现和微调
