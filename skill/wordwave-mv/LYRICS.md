# WordWave 歌词格式说明

> 引擎按**行**消费歌词：一行 = 一个镜头文案。空行 = 段落间隔。
> Agent 拿到任何格式的歌词，都按下表整理成引擎语法后交给 `make_mv.py`。

## 基础语法（引擎原生，来自 J.parseLyrics）

| 语法 | 作用 | 示例 |
|---|---|---|
| 普通文本行 | 一行一句歌词 | `夜色漫过城市的天桥` |
| 空行 | 段落分隔（gap，影响镜头衔接） | |
| `#` 开头 | 注释，被忽略 | `# 这是备注` |
| `[ti:xxx]` `[ar:xxx]` `[al:xxx]` | 元数据（标题/歌手/专辑），不显示 | `[ti:夜航]` |
| `[00:12.50]文字` | LRC 时间戳，指定该句出现时间 | `[00:15.20]灯火燃烧` |
| `[间奏]` / `[间奏 8]` | 间奏段（只出背景和装饰不出字），可指定秒数；也认 `[interlude]` `[inst]` | `[间奏 8]` |
| `文字 \| 备注` | 行内 `|` 后是备注（制作笔记，不改变渲染）？以引擎实际渲染为准 | |
| `文字！`（半角`!`结尾） | 冲击帧（impact，重拍强调） | `奔跑吧!` |
| `*词语*` | 强调（emph，重点渲染该词） | `我们*奔向*远方` |
| `句1 / 句2` | 手动分字组（manual chunking，控制一行内的切分） | `夜色 / 漫过天桥` |

## Agent 整理规则（傻瓜化处理）

1. **纯文本歌词**（最常见）→ 直接逐行传入即可，**不需要时间戳**（引擎自动按节奏规划镜头）
2. **LRC 文件**（带 `[00:12.50]` 时间戳）→ 可直接使用，引擎会按时间排序并对齐
3. **SRT 字幕文件** → 引擎**不支持**，agent 必须先转成 LRC（把 `00:00:12,500 --> 00:00:15,800` 换算成 `[00:12.50]` 起始时间，逐行转换后传入）
4. **一大段没换行的文本** → agent 按语义断句拆行（每行 6~14 字为佳，太长会被引擎再切）
5. **带段落标记**（`[Verse 1]` `[Chorus]` 等）→ 转成空行或 `#` 注释，**不要保留**（引擎不认 Verse 标记，会当歌词渲染出来）
6. **重复副歌** → 老老实实重复写行，别用"×2"之类简写
7. **歌名/歌手信息** → 用 `[ti:歌名]` `[ar:歌手]` 传入（会进方案元数据）

## 推荐格式示例

```
[ti:夜航]
[ar:未知乐队]

夜色漫过城市的天桥
灯火在玻璃上轻轻燃烧
我们说过的话像风一样

[间奏 8]

明天还在很远的地方
可我已经*开始*奔跑!
```

## 红线（agent 必查）

- ❌ 不要传 Markdown 源码（`**加粗**`、`# 标题` 会当文字渲染或被忽略）
- ❌ 不要保留 `[Verse]` `[Chorus]` `[Pre-Chorus]` 等英文段落标签
- ❌ 不要直接传 SRT 文件（引擎不认，必须先转 LRC）
- ❌ 不要带翻译对照、罗马音（除非用户明确要显示）
- ✅ 出片后建议用户核对：强调词、间奏位置是否符合歌曲结构
